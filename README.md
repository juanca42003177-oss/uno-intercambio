# Uno Intercambio - Worldcoin Exchange Platform

Plataforma segura de intercambio de criptomonedas integrada con Worldcoin.

## Características Principales

- 💱 Intercambiar tokens entre World Chain, Polygon y zkEVM
- 💰 Ganar rendimiento (APY) con criptomonedas
- 📤 Enviar y recibir criptomonedas
- 🔐 Validación backend de todas las transacciones
- ✅ Autenticación Worldcoin

## Quick Start

```bash
git clone https://github.com/juanca42003177-oss/uno-intercambio.git
cd uno-intercambio
npm install
npm run dev
```

## Seguridad

- ✅ JWT Tokens
- ✅ Rate Limiting (10 req/min)
- ✅ Validación backend
- ✅ Encriptación AES-256
- ✅ Input sanitization

## Redes Soportadas

- World Chain (480)
- Polygon (137)
- zkEVM (1101)

## Comisiones

- Plataforma: 0.5%
- Puente: 2%
- Gas: Variable por red
